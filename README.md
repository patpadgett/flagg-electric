## Design intent
This compare build intentionally differs from the single-page version:
- lighter editorial layout
- more rectilinear cards and ruled sections
- separate service pages for local SEO depth
- one shared stylesheet and brand mark asset
- a clearer page hierarchy for staring side-by-side against the first build
